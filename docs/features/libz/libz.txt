"libz" is zaal standard libraray implementation, which provides:
- runtime zaal APIs (print, fopen, malloc, memcpy, sockets wrappers, mmap wrappers, etc.)
  - libz.io
  - libz.math
To implement them, we should have a directory called "libz". "io" and "math" are normal filesc inside it, which acts as modules.
