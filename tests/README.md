# tests
This directory is dedicated to the TCs written for zaal.
for testing library, we use cmocka: https://cmocka.org/
Important: make sure you install cmocka on your machine. (either through package manger or build it from source)

# build/run/clean
please run `./p` in the root, then you have these options:
- "build(tests)"
- "run(tests)"
- "gdb(tests)"
- "clean(tests)"
